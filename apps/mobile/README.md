# Gav-Gav Mobile

React Native + Expo + TypeScript mobile app for the Gav-Gav MVP.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npm run start
   ```

The app uses Expo Router and is ready for screen-by-screen implementation from Figma.

The temporary start screen is located at `app/index.tsx`.
